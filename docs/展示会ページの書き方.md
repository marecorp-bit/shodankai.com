# 展示会ページの書き方

`src/content/events/<スラッグ>.md` を1件1ファイルで作る。ページは `/events/<スラッグ>/` に出る。

## いちばん大事な決まり

1. **公式ページを開いて確かめた項目だけを書く。** 確かめられなかった項目は frontmatter から**省く**（「不明」「要確認」とは書かない。ページに出さないため）。
2. **開催情報を写しただけのページにしない。** 本文（準備のポイント）は300字以上。これより短いとビルドが止まる。
3. 最新情報は公式で確認してもらう。ページの型が公式リンクと「最新の情報は必ず公式ページでご確認ください」を自動で出すので、本文で重ねて書かなくてよい。
4. 主催者・出展者には連絡しない。公開されているページだけを根拠にする。

## スラッグ

英小文字・数字・ハイフンで、展示会名と年度。例：`foodmesse-niigata-2026`、`smts-2027`。
同じ展示会の翌年度は別ファイル（`-2027`）にする。

## frontmatter

```yaml
---
name: "フードメッセinにいがた2026"            # 公式表記どおり
description: "（20〜160字）この展示会の特徴と、準備で気をつける点を1〜2文で。"
industry: food                                # food（食品）か it（DX・IT）
eventStart: 2026-11-11                         # 初日
eventEnd: 2026-11-13                           # 最終日（1日なら省く）
venue: "朱鷺メッセ 新潟コンベンションセンター"  # 確かめられたら
prefecture: "新潟県"
organizer: "フードメッセ in にいがた運営会議"
exhibitors: "食品中心、450事業者・430小間（予定）"
applicationDeadline: 2026-08-28                # 公式に締切日が書いてあるときだけ
fee: "食品・食材専用ブース 95,000円（税別）"
officialUrl: "https://foodmesse.jp/"
sources:                                       # 確かめるのに使ったページ（公式・主催者）
  - "https://foodmesse.jp/outline"
verifiedAt: 2026-10-21                         # 公式ページで確かめた日
pubDate: 2026-10-21
updatedDate: 2026-10-21                        # 直すたびに更新
---
```

- 日付はすべて `YYYY-MM-DD`。
- 「準備の日程」は `applicationDeadline` と `eventStart` から自動で逆算される。締切が分からなければ省けば、開催日からの逆算だけが出る。
- 「必要になりそうな備品」は `industry` から自動で出る（中身は `src/data/kit.ts`）。

## 本文（準備のポイント）に書くこと

このページだけの内容を書く。目安は400〜800字。見出しは `###` を使う（`##` はページの型が使っている）。

- **その展示会の性格**：来場者はどんなバイヤーか（量販・百貨店・通販・輸出など）、出展者の規模感。公式に書いてある範囲で。
- **小間・会場から決まる準備**：小間の種類（食品専用ブース等）、試食の可否、搬入の方法など、公式で確かめられたこと。そこから「何を持っていくか・どう組むか」を具体的に。
- **締切との距離**：今から間に合うか。締切が過ぎているなら、出展が決まっている会社に向けて何を前倒しすべきか。
- 書かないこと：公式ページの文章の書き写し、確かめていない数字、他社や主催者への評価。

## 公開まで

1. ブランチを切って `src/content/events/` にファイルを足す（1回の PR は3件まで）。
2. `npm run build` が通ることを確かめる。
3. PR を出す。マージは人が行う。main にマージされると Cloudflare（Workers Builds）が自動でビルドして shodankai.com に反映される。

訂正・削除は必ず人が確認する。削除する場合はファイルを消すより `draft: true` にする方が、あとで経緯を追いやすい。
